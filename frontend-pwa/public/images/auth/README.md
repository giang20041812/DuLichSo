# Ảnh trang Đăng nhập / Đăng ký

Thả ảnh của bạn vào thư mục này với đúng tên file:

| File               | Dùng cho        |
| ------------------ | --------------- |
| `login-hero.jpg`   | Trang Đăng nhập |
| `register-hero.jpg`| Trang Đăng ký   |

- Kích thước khuyến nghị: 1400×1800 (ảnh dọc), dưới 400KB.
- Không cần sửa code. Chưa có file thì trang tự dùng ảnh dự phòng trong `src/config/authImages.ts`.
- Muốn đổi tên hoặc đuôi file (webp, png...) thì sửa `src/config/authImages.ts`.
